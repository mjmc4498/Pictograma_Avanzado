# Sistema de Pictogramas Interactivo

## Descripción

El Sistema de Pictogramas Interactivo es una herramienta de comunicación aumentativa y alternativa (CAA) diseñada específicamente para niños con autismo. Construido con HTML, CSS y JavaScript puro, este sistema ofrece una interfaz intuitiva y personalizable que facilita la comunicación y el aprendizaje.

El proyecto se enfoca en la accesibilidad, la personalización y la usabilidad, proporcionando una experiencia de usuario amigable y efectiva tanto para los niños como para los terapeutas y cuidadores.

## Características Principales

- **Interfaz Intuitiva y Amigable:** Diseño claro y visualmente atractivo, construido con Bootstrap 5 y personalizado para una experiencia de usuario óptima.
- **Pictogramas Interactivos:** Más de 300 pictogramas con iconos de alta calidad de la biblioteca Iconify. Cada pictograma responde con una animación visual y reproducción de audio al ser seleccionado.
- **Construcción de Frases:** Barra de construcción de frases que permite arrastrar y soltar o seleccionar pictogramas para formar oraciones.
- **Síntesis de Voz:** Las frases construidas pueden ser reproducidas en voz alta utilizando la API de Síntesis de Voz del navegador.
- **Categorías de Pictogramas:** Los pictogramas están organizados en categorías como "Acciones y Verbos", "Animales", "Comida", "Emociones", etc., para facilitar su búsqueda y uso.
- **Sistema de Recompensas:** Recompensas visuales para reforzar positivamente la interacción del usuario y motivar el aprendizaje.
- **Personalización Avanzada (Protegida por PIN):**
    - **Gestión de Pictogramas:** Permite a los adultos (padres, terapeutas) crear, editar y eliminar pictogramas personalizados.
    - **Configuración de Idioma:** Soporte para múltiples idiomas (español e inglés por defecto).
    - **Ajustes de Accesibilidad:** Opciones para modo oscuro, alto contraste y ajuste del tamaño de la fuente.
- **Gestión de Frases:**
    - **Guardar y Reutilizar:** Las frases pueden ser guardadas para su uso posterior.
    - **Exportar a Imagen:** Las frases pueden ser exportadas como una imagen PNG para ser compartidas o impresas.
    - **Historial de Uso:** Registro de las frases utilizadas para seguimiento del progreso.
- **Almacenamiento Local:** Todas las configuraciones, pictogramas personalizados y datos del usuario se almacenan localmente en el navegador, por lo que no se requiere conexión a internet.
- **Diseño Responsive:** Totalmente adaptable a dispositivos móviles, tablets y ordenadores de escritorio.

## Cómo Utilizar

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/sistema-pictogramas-interactivo.git
   ```
2. **Abrir `index.html` en tu navegador:**
   Navega a la carpeta del proyecto y abre el archivo `index.html` en tu navegador web preferido.
